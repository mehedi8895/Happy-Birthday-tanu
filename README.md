# Taniya Birthday Surprise ❤️🌹

A mobile-first, single-file birthday surprise website made for Taniya.

## Features
- 5-second countdown
- Full-screen HAPPY BIRTHDAY reveal
- Sequential birthday wishes and Next Surprise button
- Finale with roses, flowers, hearts, and “I LOVE YOU, BOUUU! ❤️🌹”
- Responsive design for mobile and desktop
- No framework, build command, or dependencies required

## Deploy with Vercel
Import this repository into Vercel. Choose **Other** as the framework preset, leave the Build Command empty, and set Output Directory to `.`. The homepage is `index.html`.
